# Playbook Bets

Playbook Bets is a free-to-play sports betting simulation platform designed for entertainment, strategy testing, and analytics experimentation. The application allows users to create accounts, manage virtual bankrolls, place simulated wagers, and track betting performance through a secure full-stack web application.

## Disclaimer

Playbook Bets does not support or facilitate real-money gambling.

* No real-money deposits or withdrawals
* No cryptocurrency transactions
* No cash payouts
* Virtual currency only
* Simulated game outcomes for testing and entertainment purposes

## Features

* Secure email/password authentication
* Virtual bankroll system with starting balance allocation
* Sportsbook-style betting interface
* Simulated game and odds engine
* Transaction-safe bet placement workflows
* Automated bankroll updates
* Bet history and transaction tracking
* Randomized game settlement logic
* Secure user-specific data access using Row-Level Security (RLS)
